# BazaarFlow Step 20.2 — Mobil liste ve Satış başlığı

Bu küçük patch iki mobil düzenlemeyi yapar:

- Ürünler & Stok listesini 3 tam kart görünen, kendi içinde dikey snap-scroll/slider alanına çevirir.
- Kart listesindeki ikincil aksiyon satırını kaldırır; kart dokunuşu detay ekranını açmaya devam eder, Stok Ekle üstte kalır.
- Mobil Hızlı Satış ekranına diğer sayfalarla aynı seviyede `Satış` başlığı ekler.
- Masaüstü Hızlı Satış başlığı ve davranışı değişmez.
